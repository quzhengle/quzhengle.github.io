# 裸眼3D · 全宽 SBS 左右并排

纯前端静态页面：上传本地视频后，在浏览器里预览 **全宽 SBS（左右并排）**，点一次从片头录到片尾并自动下载。

视差强度固定为 8，没有滑杆。只做 SBS，不做其他立体格式，也不导出 PNG。

## 画面怎么处理

左右眼各自 **完整保留原画面**（四边都在，比例不变）。固定视差只把两眼水平错开，错开后露出来的空隙用黑边补上，不裁切、不拉伸。

这是 **全宽 SBS**：成片宽度是两只眼并排，高度与单眼相同，所以成片比原片更宽。  
这不是 **半宽 SBS**。半宽会把每只眼横向压成一半，让成片比例回到原片。播放器请选择 Full / Side-by-Side，不要选 Half。

预览按手机屏幕等比缩小，宽高比与下载文件的像素尺寸一致。页面上会写出导出宽高。

单眼画面的长边最多 960 像素（整帧缩小，不是裁切），避免手机预览和录制时分辨率过高而掉帧。

## 保存

点一次「保存到系统相册」：从片头录到片尾，结束后浏览器自动下载（优先 MP4，否则 WebM）。预览可以听到原声，下载文件也带原声。

浏览器 **不能直接写入** 手机「照片」相册。下载后请用系统分享或「文件」应用再存进相册。单次录制安全上限约 3 分钟。

## 本地打开

```bash
python3 -m http.server 8765 --bind 0.0.0.0
```

在仓库根目录执行，然后打开 `http://127.0.0.1:8765/`。

## 测试

```bash
npm test
npm run test:browser
```

`npm test` 检查布局：全帧取样、视差只补黑边、全宽而不是半宽。  
`test:browser` 用合成的横屏 / 竖屏视频（带四边色块、角标文字、移动白条和 440Hz 声音，帧率各不相同）在 Chrome 里走预览和真实导出，再检查尺寸、四边、时长、音量和帧间隔。测试在桌面版无头 Chrome 的手机视口里进行，不是真机。

浏览器若支持，会优先用 H.264 MP4。有的桌面 Chrome 会把音轨编成 Opus，系统相册未必接受；Safari 通常能给出更适合相册的 MP4。无论哪种编码，页面都只是下载文件。
