# 裸眼3D · SBS 左右并排

纯前端静态页面：上传视频后，在浏览器内生成 **SBS（左右并排）** 立体预览，并可「保存到系统相册」（下载视频）。

> 深度固定为推荐舒适值（8），不可调节。仅 SBS 模式。真正的硬件裸眼3D 需柱镜屏。

## 如何打开（手机）

1. 启动静态服务（见下方），确保手机与服务器在同一局域网。
2. 打开：`http://<服务器IP>:8765/`
3. 上传视频，点击播放查看 SBS 效果。
4. 点一次「保存到系统相册」：从片头录到片尾后自动下载（优先 MP4，否则 WebM），无需再点一次。手机上可用系统分享/文件应用存入相册。

## 启动本地服务

```bash
python3 -m http.server 8765 --bind 0.0.0.0 --directory /workspace/naked-eye-3d
```

访问：`http://127.0.0.1:8765/`

## 功能

- 上传视频（选择 / 拖拽）
- SBS 实时预览
- 深度固定为 8（无滑杆）
- 播放 / 暂停、重新生成、更换视频
- 「保存到系统相册」：MediaRecorder 录制 canvas 并下载

## 提示

- 依赖 `MediaRecorder`；点一次后自动录到片尾并下载（最长约 3 分钟安全上限）。
- 若浏览器支持则优先 MP4，否则 WebM。
- **音频**：保存时通过 Web Audio（`MediaElementSource` → `MediaStreamDestination`）混入原视频音轨；预览仍静音。若源视频无音轨或浏览器拦截，导出可能仍为无声。
